Two eras at once

Both revisions at once

A request that names 2026-07-28 in _meta is handled statelessly; initialize, and any request without it, falls back to the handshake (2025-11-25 back to 2024-11-05). An unsupported version returns -32022 with every version the server speaks.

Two ways to speak

Streamable HTTP & stdio

to_asgi hands a moonasgi app to mooncat: one POST per message, origin-checked against DNS-rebinding. run_stdio speaks line-delimited JSON on native stdio, built on serve_lines for any stream.

Two ways to write

Register, or annotate

Call server.tool(name, handler, input_schema=…) by hand, or mark a function #mcp.tool and let the generator write the same registration, with the JSON Schema from the argument types.

Three capability kinds

Tools, resources, prompts

Tools Resources Prompts

Every capability is one component with the same lifecycle: register it, list it, call it, get a typed result back.
