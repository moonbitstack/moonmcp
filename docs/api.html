The public surface

Every type, function, method and value moonmcp exposes, drawn straight from the compiled package interfaces. Generated from source — it cannot drift from the code.

Three capability kinds give the reference its colours: tools, resources, prompts. Everything else is the server, the wire, or the errors in between.

struct
pub struct Server { info : @types.Implementation instructions : String? ttl_ms : Int32 scope : Scope

An MCP server: the tools, resources, resource templates and prompts it offers, and who it says it is. It speaks both eras of the protocol. A request carrying its protocol version in _meta is served statelessly under the 2026-07-28 revision; an initialize request opens the handshake of the revisions before it. The same server is reached over Streamable HTTP with to_asgi, over stdio with run_stdio, or by any transport of your own through handle. ttl_ms and scope are the caching hints every list result carries under the 2026-07-28 revision. The presets say "stale at once" and "this caller only", the cautious end of both, since a server that changes what it lists per caller would otherwise leak one caller's list to the next.

pub async fn Server::serve_lines(Self, async () -> String?, async (String) -> Unit) -> Unit

Serve newline-delimited JSON-RPC: read a line with read until it gives None, answer it, and write the reply as one line (← the stdio transport, over any pair of streams). A line that is not JSON is answered with a parse error; a blank one is skipped. Requests are answered one at a time, in the order they arrive.

fn
pub fn Server::to_asgi(Self, path? : String, origins? : Array[String], debug_page? : String) -> async (@spec.Scope, async () -> @spec.Event, async (@spec.Event) -> Unit) -> Unit

The server as an ASGI application serving the MCP endpoint at path. Run it with mooncat, or mount it beside a moonapi app. Every message is its own POST, answered with one JSON object, or 202 for a notification. Sessions, the GET stream and DELETE belong to the revisions before 2026-07-28 and are optional there; this server keeps no session, so GET and DELETE answer 405. A request whose Origin header names another site is refused with 403, as the transport requires against DNS rebinding. An origin passes when its host is the request's own Host, a loopback address, or one listed in origins. debug_page names a path the debug page is served at, beside the endpoint: a browser opened on it lists what the server offers and calls it, in both eras of the protocol. Nothing is served there unless you name the path, and the path must differ from the endpoint's; the page is off by default and never carries credentials of its own, so it is for development servers.

Offer a tool whose handler returns any JSON value (← @mcp.tool). An object becomes structured content as well as text; anything else becomes text.
