Revision 2026‑07‑28 — stateless

No handshake. Every request names its version in _meta, and the server answers it on its own. Client and server keep no shared state between calls.

2026‑07‑28

List, call, read

Field names follow the MCP wire. The resultType and server fields are moonmcp's additions for this revision; every other result is plain MCP.

Client
tools/list · POST /mcp
{
  "jsonrpc": "2.0",
  "id": 1,
  "method": "tools/list",
  "params": {
    "_meta": {
      "io.modelcontextprotocol/protocolVersion": "2026-07-28",
      "io.modelcontextprotocol/clientCapabilities": {}
    }
  }
}
Server
result · tools/list
{
  "jsonrpc": "2.0",
  "id": 1,
  "result": {
    "tools": [
      { "name": "add", "description": "Add two numbers",
        "inputSchema": { "type": "object",
          "properties": { "a": { "type": "number" }, "b": { "type": "number" } },
          "required": ["a", "b"] } },
      { "name": "greet", "description": "Greet someone by name",
        "inputSchema": { "type": "object",
          "properties": { "name": { "type": "string" } }, "required": ["name"] } }
    ],
    "resultType": "tool/list",
    "server": { "name": "demo", "version": "1.0.0" }
  }
}

Revision 2025‑11‑25 — the handshake

The older shape. A client opens with initialize, reads the server's capabilities, and only then lists, calls and renders. moonmcp answers every revision back to 2024‑11‑05 without a config change.

2025‑11‑25

initialize, then work

A request that does not name a version falls back to this handshake. The same server, the same tools — only the opening moves differ.

Client
initialize
{
  "jsonrpc": "2.0",
  "id": 1,
  "method": "initialize",
  "params": {
    "protocolVersion": "2025-11-25",
    "capabilities": {},
    "clientInfo": { "name": "claude-desktop", "version": "1.0.0" }
  }
}

result · initialize
{
  "jsonrpc": "2.0",
  "id": 1,

    "serverInfo": { "name": "demo", "version": "1.0.0" }

}

The debug page

Give to_asgi a path and a browser page appears beside the endpoint: it lists every capability, fills an argument form from each input schema, and shows the JSON-RPC request next to the reply it got back — in either era. The five frames below are real captures of that page.

Run it yourself

The frames above are the demo server over Streamable HTTP. Build it for native and the debug page is served at /debug next to the endpoint:

$moon run src/examples/http --target native

Then open http://127.0.0.1:12000/debug. Off by default — the page appears only because the server was built with to_asgi(debug_page="/debug"); a server that is not being debugged answers exactly as before.
